# 🧰 DevToolBox

Simple, fast and privacy-friendly developer utilities.

DevToolBox is an open-source collection of useful tools that run directly in your browser.

## ✨ Features

- 🔄 JSON Formatter & Minifier
- 🔐 Password Generator
- 🔤 Base64 Encoder / Decoder
- 🔗 URL Encoder / Decoder
- ⏱️ Unix Timestamp Converter
- 🌙 Dark Mode
- 📋 Copy results easily
- 📱 Responsive design
- 🔒 No signup
- 🛡️ No tracking
- ⚡ Runs directly in the browser

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- Git & GitHub

### How to contribute

1. Choose an issue.
2. Comment that you would like to work on it.
3. Fork this repository.
4. Create a new branch.
5. Make your changes.
6. Run `npm run build`.
7. Commit and push your changes.
8. Open a Pull Request.
