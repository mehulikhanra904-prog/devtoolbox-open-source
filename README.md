# 🧰 DevToolBox

Simple, fast and privacy-friendly developer utilities.

DevToolBox is an open-source collection of useful tools that run directly in your browser.

## ✨ Features

- 🔄 JSON Formatter & Minifier
- 🔐 Password Generator
- 🔤 Base64 Encoder / Decoder
- 🔗 URL Encoder / Decoder
- ⏱️ Unix Timestamp Converter
- 🌙 Dark Mode
- 📋 Copy results easily
- 📱 Responsive design
- 🔒 No signup
- 🛡️ No tracking
- ⚡ Runs directly in the browser

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- Git & GitHub
